# MVP CLI Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local Python CLI that runs a piano audio transcription pipeline and produces MIDI, MusicXML, and PDF artifacts.

**Architecture:** Keep external tools behind small adapters. The pipeline owns file naming and stage order. Pure logic, such as cleanup thresholds and command construction, is tested without requiring ffmpeg, model packages, MusicXML, or MuseScore to be installed.

**Tech Stack:** Python 3.11+, argparse, pathlib, subprocess, pytest, optional runtime integrations with ffmpeg, piano_transcription_inference, music21, and MuseScore.
